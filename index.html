Projects

Selected engineering work

These cards combine thesis, academic, and professional projects. Each one is presented as a compact case study so the website can be published directly as a public portfolio.

Scania · Master's thesis

LM-80 LED test station

Designed a scalable LM-80 compliant LED reliability testing system for long-term characterization, automated data acquisition, traceable calibration, predictive analysis, and live monitoring.

  • Modular 19-inch rack architecture for industrial deployment.
  • MQTT over LAN/Wi-Fi to broker and database pipeline with long-term storage mapping.
  • Python dashboard, Linux-based logging, and remote configuration workflows.
Robotics · computer vision

Vision-based quadruped navigation

Built a low-cost navigation system for a quadruped robot using monocular vision, remote compute, OpenCV, YOLO, and ROS2 instead of expensive LiDAR hardware.

  • HSV-based adaptive colour filtering and camera calibration.
  • Perspective-based distance estimation and object identification.
  • Integrated perception with path planning and obstacle avoidance.
Sensing · signal conditioning

Water flow direction sensing

Developed an underwater strain-gauge-based sensing system with COMSOL simulation, Wheatstone bridge configuration, custom PCB design, embedded filtering, and waterproof mechanical housing.

  • Low-cost alternative to traditional flow sensors.
  • Custom analog front-end and signal-conditioning path.
  • Validated through controlled environmental experiments.
Control systems · embedded hardware

100-actuator metronome system

Designed a synchronized multi-actuator control system using Arduino and ESP32 architectures, with independent BPM, frequency, and pitch control across a large actuation array.

  • Scalable actuator driver architecture and hardware interface.
  • Timing synchronization logic optimized for low latency.
  • Applicable to haptics, robotics, and mechanical synchronization.
Capgemini Engineering

Motor driver systems

Developed reliable motor driver hardware for automotive and industrial use with schematic design, PCB layout support, worst-case analysis, prototype bring-up, validation, and firmware integration.

  • Component selection under electrical, thermal, and lifecycle constraints.
  • DVP-aligned verification, signal validation, and CAN-analyzer-based control.
  • Improved reliability and automotive compliance readiness.
Avionics · power electronics

Aircraft power supply conversion

Designed and validated high-frequency power conversion systems from aircraft input ranges to regulated 48V and 12V outputs using simulation, testing, documentation, and aerospace-oriented workflows.

  • AC-DC/DC-DC conversion under 135–195V and 400–800Hz aircraft sources.
  • PSpice and TI power tool simulation with load-condition characterization.
  • Validation aligned with aviation-grade process expectations.
